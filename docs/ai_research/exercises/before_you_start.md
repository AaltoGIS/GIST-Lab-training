# Before you start

This is a hands-on path to get set up and working with the coding agent. Work through
the exercises in order, on your own project. They cover the practical skills from this
half of the theme, not the responsibility topics — those are for discussion with the
group.

Each exercise ends with a **Done when** check so you know you have it. There are no full
solutions; the point is to do it on real work.

- Read the responsibility pages first, especially
  {doc}`Data protection and privacy </ai_research/data_protection>`. You will be working
  on a real project, so the rules there apply from step one.
- **Pick a suitable project.** Choose something safe to experiment on: under version
  control with Git, holding no sensitive or personal data, and where you have the tool
  access you need. If your current work does not fit — a manuscript-only project,
  restricted data, a very early-stage idea — use the lab's starter project instead:
  [github.com/AaltoGIS/research-portfolio](https://github.com/AaltoGIS/research-portfolio),
  where you build your own **research portfolio website** with Claude and publish it
  free on GitHub Pages. You need no front-end experience — that is the point of the
  project — and the repository's README walks you through the technology choices,
  starter prompts, and deployment. It is real work with nothing sensitive in it, it
  produces something you actually want (a beautiful page showcasing your research),
  and every exercise here can be done on it: use the repo as a template on GitHub,
  clone yours, and go. This track assumes a coding project; adapt the tasks if yours
  is different.
