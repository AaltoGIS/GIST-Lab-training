# 3. Give it context

Write a project `CLAUDE.md`: run `/init` in the project to get a first draft, then
correct it and add what the agent could not have discovered — the conventions, the
"always do X" rules. Check your global one (`~/.claude/CLAUDE.md`) for the facts that
hold across all your projects. Optionally, draft a context portfolio
({doc}`Teaching Claude who you are </ai_research/teaching_claude>`).

**Done when:** Claude Code uses facts from your `CLAUDE.md` without you repeating them.
