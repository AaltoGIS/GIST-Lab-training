# 6. Plan, then cross-review

For a larger piece of work, describe the outcome and the objective, ask the agent to
**interview you** and draft a plan in `plans/` from your answers, using the five-part
skeleton in {doc}`Efficient prompting strategies </ai_research/how_we_work>`. Review
the plan before you
build — yourself, and with a second model if you have one (`/review-plan-codex`, or a
fresh Claude session; see
{doc}`Higher-quality results </ai_research/higher_quality_results>`).

**Done when:** you have a reviewed plan and a small, reviewable change built from it.
